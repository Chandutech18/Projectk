# Royal Korutla Monorepo 👑

A comprehensive hyperlocal digital directory & multi-service web platform for Korutla town.

## Architecture 🏛️

- **`frontend/`**: Next.js (App Router, Tailwind CSS, TypeScript)
- **`backend/`**: Java Spring Boot 3.x REST API (Spring Data JPA, H2 Database)

## Quick Start 🚀

### 1. Run Backend (Java Spring Boot)
```bash
cd backend
mvn spring-boot:run
```
Backend runs on `http://localhost:8080`.
H2 Console: `http://localhost:8080/h2-console`

### 2. Run Frontend (Next.js)
```bash
cd frontend
npm run dev
```
Frontend runs on `http://localhost:3000`.

## Features ✨
- Business Directory & Categories
- Food Delivery & Restaurant Menu
- Grocery Stores & Product Listings
- Hospitals & Doctors Directory
- Local Jobs & Real Estate Listings
- Offers, Promotions & Reward Points
